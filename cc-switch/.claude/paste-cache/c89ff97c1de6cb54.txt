› 如果要配置成 **GitHub 账号级 SSH Key**，不是仓库级 Deploy Key，需要修改两处：

  1. GitHub 添加公钥的位置；
  2. SSH 密钥和 Git 远程地址的配置方式。

  账号级 SSH Key 可以访问该 GitHub 账号有权限的多个仓库。

  ---

  # 一、服务器生成账号级 SSH Key

  建议不要复用原来的仓库专用密钥，单独生成一把账号级密钥：

  ```bash
  mkdir -p -m 700 ~/.ssh

  ssh-keygen -t ed25519 \
    -f ~/.ssh/github_all \
    -C "amd-server-github-account"
  ```

  如果提示：

  ```text
  Enter passphrase
  ```

  可以：

  - 服务器需要无人值守使用：直接回车，不设置密码；
  - 安全要求较高：设置一个 passphrase，但之后 Git 操作可能需要 ssh-agent 解锁。

  查看公钥：

  ```bash
  cat ~/.ssh/github_all.pub
  ```

  只复制输出内容，格式类似：

  ```text
  ssh-ed25519 AAAA... amd-server-github-account
  ```

  不要复制私钥：

  ```text
  ~/.ssh/github_all
  ```

  ---

  # 二、添加到 GitHub 账号

  登录你要使用的 GitHub 账号后，打开：

  ```text
  https://github.com/settings/keys
  ```

  也可以通过菜单进入：

  ```text
  头像 → Settings → SSH and GPG keys → New SSH key
  ```

  填写：

  ```text
  Title:
  amd-server-account

  Key type:
  Authentication Key

  Key:
  粘贴 ~/.ssh/github_all.pub 的完整内容
  ```

  然后点击：

  ```text
  Add SSH key
  ```

  注意，这次不是进入：

  ```text
  仓库 → Settings → Deploy keys
  ```

  而是进入：

  ```text
  个人账号 → Settings → SSH and GPG keys
  ```

  ---

  # 三、配置服务器使用这把账号级密钥

  执行：

  ```bash
  cat > ~/.ssh/config <<'EOF'
  Host github.com
      HostName ssh.github.com
      Port 443
      User git
      IdentityFile ~/.ssh/github_all
      IdentitiesOnly yes
      StrictHostKeyChecking accept-new
  EOF

  chmod 600 ~/.ssh/config
  chmod 600 ~/.ssh/github_all
  chmod 644 ~/.ssh/github_all.pub
  ```

  这会让服务器访问 `github.com` 时：

  - 使用 SSH 443 端口；
  - 使用 `~/.ssh/github_all` 私钥；
  - 不尝试其他 SSH 密钥；
  - 首次连接时自动接受 GitHub Host Key。

  ---

  # 四、验证账号身份

  执行：

  ```bash
  ssh -T git@github.com
  ```

  如果配置正确，会看到类似：

  ```text
  Hi Double-wk! You've successfully authenticated, but GitHub does not provide shell access.
  ```

  其中的 `Double-wk` 必须是你添加这把 SSH Key 的 GitHub 账号。

  如果看到的是其他账号，说明服务器实际使用了其他密钥，需要检查：

  ```bash
  ssh -G github.com | grep -E 'hostname|port|user|identityfile|identitiesonly'
  ```
